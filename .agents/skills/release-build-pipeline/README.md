# Release Build Pipeline Skill

Cross-platform desktop packaging and release build automation skill for GeoSource Tauri applications.

## Overview
- **Domain**: Desktop Installer Packaging, Version Synchronization, Code Signing, Auto-Updater.
- **Key Technologies**: Tauri v2 Bundler, NSIS, MSI, Cargo Version Sync.

## Contents
- `SKILL.md`: Main release pipeline instructions.
- `scripts/verify_release_readiness.ps1`: Release verification check script.
- `references/release_packaging_guide.md`: Complete release packaging guide.
- `resources/release_checklist.md`: Step-by-step checklist artifact for release readiness.
- `tests/test_validation.ps1`: Skill validation test suite.
