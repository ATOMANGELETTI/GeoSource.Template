# `always-beautiful` Example Implementations

This folder contains reference Svelte component examples demonstrating how unpolished, flat UI code is transformed into beautiful, state-of-the-art visual components.

## Directory Layout

- `minimal/BeforeAfterComponent.svelte`: Illustrates an unpolished raw button/card component side-by-side with its `always-beautiful` polished equivalent.
- `dashboard/PolishedDashboard.svelte`: A full, real-world dark-mode dashboard component showcasing glassmorphism cards, animated statistics, gradient headers, and interactive hover feedback.
