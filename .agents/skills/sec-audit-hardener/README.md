# Security Audit Hardener Skill

Security auditing and IPC hardening skill for GeoSource Tauri desktop applications.

## Overview
- **Domain**: Desktop App Security, Tauri v2 Capabilities, IPC Hardening, Cargo Audit.
- **Key Technologies**: Tauri v2 Permissions System, Rust `keyring`, `cargo-audit`, CSP.

## Contents
- `SKILL.md`: Main security rules and workflow.
- `scripts/audit_capabilities.ps1`: Capability policy security check script.
- `references/security_hardening.md`: Security hardening architectural guide.
- `resources/capability_policy_stub.json`: Example Tauri v2 capability configuration file.
- `tests/test_validation.ps1`: Skill validation test suite.
