# Design Systems Pro Examples Gallery

This directory contains concrete example implementations showcasing design tokens and component design across multiple design systems.

---

## 📁 Examples Structure

1. **`minimal-tokens/`**:
   - `tokens.json`: Raw W3C-compliant token definitions.
   - `theme.css`: Compiled CSS custom variables generated by `scripts/generate_system_tokens.ps1`.

2. **`multi-system-gallery/`**:
   - `Material3Card.tsx`: Material Design 3 card with tonal elevation & rounded pill badges.
   - `AppleHIGCard.tsx`: Apple HIG card featuring vibrant glassmorphism & SF Pro typography.
   - `FluentCard.tsx`: Microsoft Fluent UI 2 card with Mica material & subtle drop shadow.
   - `ShadcnCard.tsx`: Minimalist dark mode Shadcn/Radix UI card with clean CSS variable bindings.
