# Material Design 3 (M3) Specification Guide

Google's Material Design 3 (Material You) introduces Dynamic Color driven by HCT (Hue, Chromaticity, Tone) color spaces, 24dp elevation scales, organic pill shapes, and expressive state layers.

---

## 🎨 Color Palette & Tokens

### Primary Roles
- **Primary**: `#6750A4` (M3 Baseline Purple)
- **On Primary**: `#FFFFFF`
- **Primary Container**: `#EADDFF`
- **On Primary Container**: `#21005D`

### Surface & Background Roles
- **Surface**: `#FEF7FF`
- **Surface Dim**: `#DED8E1`
- **Surface Bright**: `#FEF7FF`
- **Surface Container**: `#F3EDF7`
- **On Surface**: `#1D1B20`
- **Outline**: `#79747E`
- **Outline Variant**: `#CAC4D0`

---

## 🔤 Typography (Roboto / Google Sans)

- **Display Large**: 57px / 64px line height / Regular (400)
- **Headline Large**: 32px / 40px line height / Regular (400)
- **Title Medium**: 16px / 24px line height / Medium (500)
- **Body Medium**: 14px / 20px line height / Regular (400)
- **Label Large**: 14px / 20px line height / Medium (500)

---

## 📐 Shape & Corner Radii

- **Extra Small**: `4px`
- **Small**: `8px`
- **Medium**: `12px`
- **Large**: `16px`
- **Extra Large**: `28px`
- **Full / Pill**: `9999px` (Buttons, Chips, FABs)

---

## 🌊 Surface Elevation & Tonal Shadow

- **Level 0**: Flat surface (`shadow-none`)
- **Level 1**: `0px 1px 3px 1px rgba(0, 0, 0, 0.15), 0px 1px 2px 0px rgba(0, 0, 0, 0.30)`
- **Level 2**: `0px 2px 6px 2px rgba(0, 0, 0, 0.15), 0px 1px 2px 0px rgba(0, 0, 0, 0.30)`
- **Level 3**: `0px 4px 8px 3px rgba(0, 0, 0, 0.15), 0px 1px 3px 0px rgba(0, 0, 0, 0.30)`
