# Shopify Polaris Specification

Shopify Polaris is engineered specifically for merchant SaaS platforms and e-commerce admin tools. It highlights clear visual hierarchy, accessible color pairings, and merchant productivity.

---

## 🎨 Color Tokens

- **Surface Primary**: `#FFFFFF`
- **Surface Secondary**: `#F1F2F4`
- **Interactive Primary**: `#008060` (Polaris Green)
- **Interactive Hover**: `#006E52`
- **Text Primary**: `#202223`
- **Text Secondary**: `#6D7175`
- **Border Base**: `#C9CCCF`

---

## 🔤 Typography (SF Pro / Inter)

- **Heading 2XL**: 32px / Bold (700)
- **Heading LG**: 20px / SemiBold (600)
- **Body MD**: 14px / Regular (400)
- **Caption**: 12px / Regular (400)

---

## 📐 Card & Elevation

- **Border Radius**: `8px` (Cards), `4px` (Controls)
- **Shadow**: `0px 1px 0px rgba(0, 0, 0, 0.05)`
