# Ant Design 5.0 Specification

Ant Design is an enterprise-class UI design language developed by Alibaba, optimized for complex data-dense web and dashboard applications. Version 5.0 introduces algorithmic theme derivation (Design Tokens) and CSS-in-JS emotion architecture.

---

## 🎨 Color Palette & Tokens

- **Primary Color**: `#1677FF` (Ant Blue)
- **Success Color**: `#52C41A`
- **Warning Color**: `#FAAD14`
- **Error Color**: `#FF4D4F`
- **Background Container**: `#FFFFFF`
- **Background Layout**: `#F5F5F5`
- **Text Base**: `rgba(0, 0, 0, 0.88)`
- **Text Secondary**: `rgba(0, 0, 0, 0.65)`
- **Border Base**: `#D9D9D9`

---

## 🔤 Typography

- **Heading 1**: 38px / Bold (700)
- **Heading 3**: 24px / SemiBold (600)
- **Text Base**: 14px / Regular (400)
- **Text Small**: 12px / Regular (400)

---

## 📐 Shape & Shadows

- **Border Radius Base**: `6px`
- **Border Radius SM**: `4px`
- **Border Radius LG**: `8px`
- **Box Shadow Secondary**: `0 6px 16px 0 rgba(0, 0, 0, 0.08), 0 3px 6px -4px rgba(0, 0, 0, 0.12)`
