# Microsoft Fluent UI 2 Specification

Fluent UI 2 powers Windows 11, Microsoft 365, and modern cross-platform desktop software. It features Mica material surfaces, subtle ambient drop shadows, clear focus rings, and an 8px grid alignment.

---

## 🎨 Color Palette & Tokens

### Communication Colors
- **Brand Primary**: `#0078D4` (Communication Blue)
- **Brand Hover**: `#106EBE`
- **Brand Pressed**: `#005A9E`

### Neutral Scale
- **Neutral Foreground 1**: `#242424` (Primary Text)
- **Neutral Foreground 2**: `#424242` (Secondary Text)
- **Neutral Background 1**: `#FFFFFF` (Card Surface)
- **Neutral Background 2**: `#F5F5F5` (Canvas Background)
- **Neutral Stroke 1**: `#D1D1D1` (Control Border)

---

## 🔤 Typography (Segoe UI Variable)

- **Display**: 68px / SemiBold (600)
- **Title 1**: 28px / SemiBold (600)
- **Title 3**: 20px / SemiBold (600)
- **Body 1**: 14px / Regular (400)
- **Caption 1**: 12px / Regular (400)

---

## 🏛️ Materials & Radius

- **Corner Radius**: Small (`4px`), Medium (`8px`), Large (`12px`)
- **Mica Material**: `background: rgba(243, 243, 243, 0.5)` + `backdrop-filter: blur(30px)`
- **Shadow 4**: `0px 1.6px 3.6px 0px rgba(0,0,0,0.13), 0px 0.3px 0.9px 0px rgba(0,0,0,0.11)`
- **Shadow 16**: `0px 6.4px 14.4px 0px rgba(0,0,0,0.13), 0px 1.2px 3.6px 0px rgba(0,0,0,0.11)`
