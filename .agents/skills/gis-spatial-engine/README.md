# GIS Spatial Engine Skill

This skill equips Antigravity IDE agents with GIS engineering capabilities for GeoSource Tauri applications.

## Overview
- **Domain**: Spatial Data Engineering, Coordinate Systems, GIS Formats & Visualization.
- **Key Technologies**: Rust `geo`, `geojson`, `rstar`, `h3o`, MapLibre GL, Deck.gl, FlatGeobuf.

## Contents
- `SKILL.md`: Main instructions and workflow rules.
- `scripts/process_geojson.ps1`: Script to validate and optimize GeoJSON files.
- `references/gis_architecture.md`: In-depth GIS architecture design pattern reference.
- `resources/geojson_schema.json`: Standard GeoJSON FeatureCollection JSON schema.
- `tests/test_validation.ps1`: Skill validation test suite.
