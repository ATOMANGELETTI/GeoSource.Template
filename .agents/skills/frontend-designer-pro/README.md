# Frontend Designer Pro Skill

`frontend-designer-pro` is a specialized skill for Antigravity IDE focused on state-of-the-art UI/UX visual design for GeoSource Tauri desktop applications using React, Next.js, TypeScript, and Tailwind CSS.

## Features
- **High-Aesthetic UI Generation**: Glassmorphism cards, dynamic gradients, sleek dark mode themes, and fluid layouts.
- **Systematic Micro-Animations**: Smooth hover transitions, tactile press effects, and animated state changes.
- **Responsive Geometry**: Layouts optimized for Tauri window resizes from 1024x768 to 4K displays.
- **Automated Design Verification**: PowerShell verification scripts to audit Tailwind class usage and design tokens.

## Triggering the Skill
Use any of the following triggers:
- "design ui"
- "ui/ux design"
- "make beautiful interface"
- "tailwind design"
- "frontend-designer-pro"

## File Tree
- `SKILL.md` — Core instructions and design workflow
- `scripts/verify-ui-design.ps1` — Audits Tailwind classes and design tokens
- `scripts/format-styles.ps1` — Formats styles and sorts Tailwind utility classes
- `examples/glassmorphism-card/` — Reference implementation of a glassmorphic component
- `resources/design_tokens.json` — HSL colors, typography scales, and shadows
- `references/ui-design-system-guide.md` — Architectural guide for UI/UX visual design
- `tests/test_validation.ps1` — Automated test suite for validating skill integrity
