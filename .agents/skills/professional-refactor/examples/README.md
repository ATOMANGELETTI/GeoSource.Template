# Refactoring Examples

This folder contains template refactoring proposals demonstrating how `professional-refactor` structures plans and diff previews for user approval before modifying code.

## Included Examples

- **`simple_refactor_proposal.md`**: Micro-refactoring example (e.g., replacing `.unwrap()` error handling with typed `Result` in Rust).
- **`full_architecture_refactor_proposal.md`**: Macro-refactoring example (e.g., re-structuring IPC commands, state management, and spatial engine layer in GeoSource Tauri).
